# Tuse

Open-source YouTube Music player powered by InnerTube.

> Tuse is an independent project and is not affiliated with YouTube or Google.

## Current status

The first commit provides a Node/TypeScript project scaffold. Planned features:

- InnerTube search and recommendations
- Queue and local playlists
- Audio playback controls
- Lyrics and metadata
- Offline favorites
- Desktop and mobile packaging

## Development

```bash
npm install
npm run dev
```
